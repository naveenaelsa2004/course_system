# LuminaHub E-Learning System

A premium, Django-powered online course management system with a warm "Mocha & Parchment" theme.

## Features
- **Modern UI:** Glassmorphism and custom brown-themed design.
- **Focus Studio:** A distraction-free learning environment with ambient sounds and a Pomodoro timer.
- **Role-based Access:** Student, Instructor, and Admin dashboards.
- **Course Management:** Categories, enrollment, and progress tracking.

## Quick Setup
1. **Clone:** `git clone https://github.com/naveenaelsa2004/course_system.git`
2. **Environment:** `python -m venv venv` and activate it.
3. **Install:** `pip install -r requirements.txt`
4. **Database:** Create MySQL DB `online_course_db`.
5. **Migrate:** `python manage.py migrate`
6. **Seed:** `python seed.py`
7. **Run:** `python manage.py runserver`

For detailed instructions, see [setup_guide.md](setup_guide.md) or the setup guide artifact.
